LIV & BRENNEN — DIGITAL SCRAPBOOK

Open index.html in a browser to preview the interactive scrapbook. The photos folder must stay beside index.html.

The scrapbook includes all 15 uploaded photos, page-turn navigation, tap-to-enlarge photos, and a personal closing letter.

To publish for a QR code:
1. Upload the contents of this folder to a GitHub repository.
2. Enable GitHub Pages for the repository (Settings > Pages; deploy from the main branch/root).
3. Open the published website URL and make a QR code that points to that URL.

The QR code should point to the published website, not to the ZIP file.
